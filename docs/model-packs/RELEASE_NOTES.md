Default Model Pack for RigWorks.

This download contains seven individual character packages inside
`Default-Model-Pack.zip`. Extract that file, then import `.rig.zip` packages
with **Import avatar** and `marisa.mmd.zip` with **Import MMD**.

MMD source ZIP import is supported by the RigWorks build attached to this
release. The PMX file is converted by the player's client and cached locally.
No PMD/PMX conversion is performed while building or downloading this pack.

The Pixelized Starpop/Madoka and Misaka models were authored and exported in
Blender by CharlesKo; copyright CharlesKo. HD and MMD sources are collected
free online resources. Original authors and rights holders retain their
respective rights and terms. The separate Misaka Mikoto PMD package is omitted
because its included author readme prohibits redistribution.

The release includes offline Workbench round-trip and archive-hash checks. It
does not claim live Minecraft gameplay validation for every avatar.

## Behavior And Boundaries

The default controller calls `frame.defaultAnimation()` every tick and adds
JSON-configured blink through `Eyelid_Close_L/R`. This preserves native player
action sampling. Blink timing is newly authored, not recovered facial animation:
the original empty face stacks contain no usable deformation curves.

Only an idle clip mapping is provided. These source assets contain no authored
walk, run, jump, swim, or elytra clips. An ordinary clip layer does not override
the later full native MOTION modifier on mapped bones, so no ineffective idle
layer preset is shipped. Authors can choose the compatible clip policy through
`frame.defaultMotion()` and use the existing script APIs intentionally.

No rigid-body, cloth, spring, or contact-IK setup is claimed. Source Magica
collider empties do not contain sufficient portable physical parameters.
Rig physics and Hand contacts are disabled; Ground placement is enabled.
Dynamic toon lighting, outline/stencil behavior, finger grips, and automatic
original-weapon pairing during player actions are not included.

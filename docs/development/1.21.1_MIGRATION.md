# RigWorks 1.21.1 迁移

更新：2026-11-19。两个版本共享 Forge 标准源码，通过 Stonecutter 替换纯符号差异；结构差异使用版本条件。不要直接修改 `build/generated/stonecutter/`。

## 构建

| 节点 | Java | 加载器 | 光影 | 脚本 |
| --- | --- | --- | --- | --- |
| `1.20.1-forge` | 17 | Forge 47.1.3 | Oculus / Embeddium | KubeJS 2001 / Rhino 2001 |
| `1.21.1-neoforge` | 21 | NeoForge 21.1.259 | Iris 1.8.12 / Sodium 0.6.13 | KubeJS 2101 / Rhino 2101 |

```powershell
git submodule update --init --recursive
.\gradlew.bat buildAndCollect --console=plain
.\gradlew.bat :1.21.1-neoforge:runClient -PwithKubeJS --console=plain
```

引擎子模块固定在包含 Iris/PBR 修复与 54 字节 GPU 顶点兼容的 `multiversion` 提交。独立 Gradle 构建编译匹配的引擎节点；官方映射开发 JAR 不作为 RigWorks 发布内容。正常运行目录分别为 `run/` 和 `run-1.21.1/`。

## 已适配

- NeoForge `CustomPacketPayload` / `StreamCodec` 可选协议；保留 catalog/request/chunk、16 KiB 分块、SHA-256、revision/CAS、服务器隔离缓存和分享开关。必须完整协商十种 payload 后才启用分享。
- `SavedData.Factory` 与注册表参数；保存格式保持兼容。
- KubeJS 2101 插件接口、绑定、真实客户端 reload 入口和日志钩子；失败不替换有效控制器，成功空载清理旧控制器。
- Rhino 2101 包装与类可见性接口、预算和尾递归保护；旧版同类漏洞也补齐。见 [脚本重载说明](../guides/KUBEJS_RELOAD_LIFECYCLE.md)。
- 原版动作渲染器、玩家皮肤模型、实体缩放、物品数据组件、顶点提交和法线矩阵接口。
- 装备工作台滚轮、无模糊背景、Gizmo 相机矩阵、最后一个描边四边形提交。
- 公共工作区由 AssimpLoader 提供两级导航、视口、属性、任务与项目接口。RigWorks 注册 Characters，以及标记项目在公共 Edit 中的 Rig / Actions / Equipment / Behavior 面板；普通 Model 不启用这些功能。Nodes 并入引擎 Edit / Tree，两版本使用相同接口。
- 装备编辑相机按实际 FOV、视口、模型姿态包围盒及根变换取景；默认自由穿过方块，不再受原版第三人称墙壁推近影响。身体、手部与冻结的睡眠位移保持同一坐标系。
- NeoForge 内存配置与磁盘事务，保留原子保存、外部重载和注释。
- 双节点生产、测试、验收源码构建；模组元数据与资源包版本分离。ModernUI 旧编辑器已由引擎清理，不再引入运行依赖。

## 测试脚本隔离
